STEP 1 — ONE SOURCE OF TRUTH FOR THE SCHEME (src/theme/ThemeProvider.tsx)
- mode is "light" | "dark" | "system", saved in AsyncStorage (key "themeMode"), default "system". Load it before rendering any screen.
- Compute the scheme in ONE place only:
    const systemScheme = useColorScheme();   // from react-native
    const scheme = mode === "system" ? (systemScheme ?? "light") : mode;
- useEffect on [mode]: Appearance.setColorScheme(mode === "system" ? null : mode).
- useTheme() returns { colors, scheme, isDark, mode, setMode }. NO component may read the system scheme directly. Everything uses useTheme().
- Add in dev only: console.log("[theme]", { mode, systemScheme, scheme }) every time any of them changes.
- Config: in app.json set expo.userInterfaceStyle to "automatic". Also search for expo.ios.userInterfaceStyle and for app.config.js/ts: if they set "light", remove or change them to "automatic". Write in your reply that I must restart with "npx expo start --clear" and fully close and reopen Expo Go.
- StatusBar: style = isDark ? "light" : "dark" (explicit, not "auto").
- Remove the 250 ms background cross-fade from Patch G. The switch is instant, so colors can never be half-changed.

STEP 3 — COMPONENT RULES (apply to every screen and component)
- WhiteChip (paperclip button, active tab marker, selected segmented option, toast): background chipBg, border chipBorder. Every Text/Icon inside uses onChip, except the active tab icon, which uses gold.
- Text on the screen background or on glass: text (main) or textMuted (secondary). Icons: text, iconInactive or gold. Always pass the "color" prop to every lucide icon from a token; never rely on a default.
- Primary button: primaryBg + onPrimary. Send button (gold circle): gold + onGold.
- TextInput: color = text, placeholderTextColor = placeholder, selectionColor = gold, keyboardAppearance = isDark ? "dark" : "light". Field background = fieldBg, border = fieldBorder.
- Native controls follow tokens too: Switch (trackColor, thumbColor), Slider (gold), ActivityIndicator, RefreshControl.
- Bottom sheet backdrop = backdrop. The "Eliminar" text uses danger.
- GradientBackground: gradient from bgTop to bgBottom, blobs use blobA and blobB, all from useTheme().
- Camera screen: it stays dark in both modes. Inside it only, use fixed values: white text and icons on dark glass. It must not use light-mode tokens.
- No component may use a color that is not a token.
