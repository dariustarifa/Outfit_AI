PROJECT: Mobile app that recommends outfits. Working name: "Outfit".

READ THIS FIRST
This project will be sent to you in several messages (phases). In THIS message, do ONLY the "SETUP TASKS" at the end. Do NOT build any real screen yet. Read everything before writing code.

APP IDEA (context only)
1. The user enters name, age, height, a full-body photo and their city.
2. The user photographs their clothes (the "wardrobe"), with an optional note per photo.
3. The home screen greets the user, shows time and local weather, and has a button "¿Cuál es el plan de hoy?". The user writes a request and the app recommends outfits using the user's own clothes and the weather.
4. A profile screen lets the user edit their data and their wardrobe.

LANGUAGE RULES
- Everything the user sees is in SPANISH. Exact Spanish texts are written in quotes in the prompts. Use them exactly.
- Code, file names, variable names and comments are in ENGLISH.

TECH STACK (use exactly this, do not add or replace libraries)
- Expo (React Native) + TypeScript + Expo Router.
- This is a NATIVE mobile app. Do NOT build a website. Do NOT use HTML, CSS or react-dom.
- Libraries: expo-font, expo-blur, expo-haptics, expo-linear-gradient, react-native-svg, react-native-reanimated, react-native-gesture-handler, expo-camera, expo-image-picker, expo-document-picker, expo-file-system, @react-native-async-storage/async-storage, lucide-react-native (icons).
- Target iOS first. The app must not crash on Android.
- No backend, no login. All data is stored on the device.

FONTS
- "Satoshi" (400, 500, 700): ALL text.
- "Melodrama" (500): ONLY big headlines.
- Files go in assets/fonts/ with these names: Satoshi-Regular.otf, Satoshi-Medium.otf, Satoshi-Bold.otf, Melodrama-Medium.otf (.ttf is also fine).
- Load them with expo-font. Do not render any screen until fonts are loaded.

BACKGROUND (component GradientBackground)
- Vertical LinearGradient from backgroundTop to backgroundBottom.
- Plus 3 soft color blobs made with react-native-svg RadialGradient circles (about 320pt diameter, center color at 60% opacity fading to 0% at the edge): sand at bottom-left, gold at bottom-right, sage at middle-right. They sit in the lower half of the screen.
- The blobs are REQUIRED: the glass effect needs colored content behind it to look like glass.

GLASS EFFECT (component GlassView, reusable)
Goal: crystal clear glass. NOT frosted, NOT matte, NOT a solid white box. Low-to-medium opacity.
Layers from bottom to top:
1. BlurView from expo-blur, intensity 45, tint "light".
2. LinearGradient overlay from rgba(255,255,255,0.32) (top-left) to rgba(255,255,255,0.06) (bottom-right).
3. 1px border with color glassBorder.
4. Soft shadow: color #000, opacity 0.08, radius 24, offsetY 8.
The container uses overflow hidden and a borderRadius prop. On Android, if blur does not work, fall back to a plain rgba(255,255,255,0.35) background.

HAPTICS (src/haptics.ts, wrap every call in try/catch)
- tapLight(): Haptics.impactAsync(Light)
- selection(): Haptics.selectionAsync()
- success(): Haptics.notificationAsync(Success)

ANIMATION RULES (react-native-reanimated)
- Springs: damping 20, stiffness 220, mass 1.
- Fades: 250 ms.
- Every pressable button scales to 0.97 while pressed.
- Screens enter with fade + 12pt upward slide.
- Never use abrupt jumps.
