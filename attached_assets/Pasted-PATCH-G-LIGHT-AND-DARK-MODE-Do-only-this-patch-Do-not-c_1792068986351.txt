PATCH G — LIGHT AND DARK MODE. Do only this patch. Do not change layout, texts or animation.

1) THEME SYSTEM
- Convert theme.ts into two palettes: lightColors and darkColors (values in section 2). Create a ThemeProvider and a hook useTheme() that returns { colors, isDark, mode, setMode }.
- mode is "light" | "dark" | "system". Default "system". Save it in AsyncStorage (key "themeMode") and load it before rendering screens.
- When mode changes, call Appearance.setColorScheme(null | "light" | "dark") from react-native (null = follow the system). This makes native elements (keyboard, native glass, alerts) follow the choice.
- app.json: change "userInterfaceStyle" from "light" to "automatic". Without this, dark mode does NOT work on iOS.
- StatusBar style: "dark" in light mode, "light" in dark mode.
- Every component must use useTheme().colors. Search the whole code for imports of the old static colors and for hard-coded hex or rgba colors, and replace them with tokens. Exceptions: rgba(0,0,0,x) backdrops, and the camera screen, which stays dark in both modes.
- Changing the mode updates every screen instantly, with a 250 ms cross-fade of the background. No restart needed.
